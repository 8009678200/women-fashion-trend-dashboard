## 🚀 Project Overview

This project analyzes women's fashion product data and provides interactive insights through visualizations, statistical summaries, and AI-based sentiment analysis.

Users can upload their own CSV files, explore product trends, visualize ratings and sales performance, and perform sentiment analysis using a Transformer-based NLP model.
